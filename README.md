# PELA Demo

A demonstration Post-Entry Language Assessment built as a single static HTML file (`index.html`).
Demo items only; not a validated instrument. All state stays in the browser; results and the interaction log can be downloaded as JSON.

## Host on GitHub Pages
1. Create a new public repository (e.g. `pela`).
2. Add file > Upload files > drop in `index.html`, then Commit.
3. Settings > Pages > Build and deployment > Deploy from a branch > `main` / `(root)` > Save.
4. After a minute or so the site is live at `https://<username>.github.io/pela/`.
